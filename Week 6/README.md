### Key Learning

* Learned to install and manage Python packages using UV.
* Set up isolated virtual environments to manage project dependencies.
* Learned to run another person's Python code by installing the required dependencies.
* Understood how the correct project environment helps ensure consistent execution and reduces package compatibility issues.

### Key UV Commands

* **`uv init`**: Initialise a new Python project.
* **`uv add`**: Add packages, such as Pandas, to the project dependencies.
* **`uv run`**: Execute Python scripts within the project environment.
* **`uv remove`**: Remove packages from the project dependencies.
